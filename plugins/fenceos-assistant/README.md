# FenceOS Assistant

FenceOS Assistant walks a fence company through setting up FenceOS: your products, prices, gates, add-ons and material lists, one step at a time. If you ask for it, a second skill helps you build a Matrix budget and a Cash Copilot cash plan.

## What you need

- The Claude desktop app or the ChatGPT desktop app, with browser control turned on.
- Your own FenceOS sign-in. You sign in yourself; never share a password or code with the assistant.

## How to start

Open FenceOS in the controlled browser, sign in, and say: **"Help me get set up in FenceOS."**

The assistant looks around first, then proposes each batch of changes and asks before it saves anything. After saving, it reloads and reads the result back to you.
