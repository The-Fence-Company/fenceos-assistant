# FenceOS Assistant

FenceOS Assistant walks a fence company through setting up FenceOS: your products, prices, gates, add-ons and material lists, one step at a time. On request, a second skill builds a Matrix budget and Cash Copilot cash plan.

## What you need

- The Claude desktop app or the ChatGPT desktop app, with browser control turned on.
- Your own FenceOS sign-in. Never share a password or code with the assistant.

## How to start

Open FenceOS in the controlled browser, sign in, and say: **"Help me get set up in FenceOS."**

It looks around first and asks before saving each batch. After saving, it reloads and reads the result back.

Optional: admins can connect FenceOS Intelligence, read-only, for company figures and conversations.

## Updates

When a skill starts, the assistant checks for a newer version and tells you how to update.
